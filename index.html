Featured Project

Cortex

A full AI agent orchestration platform built from zero. Visual DAG-based flow builder for designing, testing, and deploying multi-step AI agent workflows at enterprise scale.

Architecture: Spring Boot backend on Java 21 using Spring AI's ChatClient with advisor chains and tool-calling patterns, persisted to MongoDB Atlas on Azure. Agents are composed as directed acyclic graphs (DAGs) where each node represents a flow step — signal collection, AI reasoning, guardrails, or actions — with configurable routing between nodes. Domain gateway routes to configurable model providers (OpenAI, Azure OpenAI, or custom endpoints). NBA workspace supports 190K-monthly-volume load simulation with p50/p95/p99 latency reporting and circuit-breaker tuning. React frontend with Monaco editor, visual DAG canvas for flow authoring, real-time execution tracing, and a seed-bundle system for bootstrapping entire workspaces.
